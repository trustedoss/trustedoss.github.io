## 1. 자체 인증 등록 절차

### 1단계 — 사전 확인

등록 전 아래 항목을 확인한다:

- [ ] `output/conformance/gap-analysis.md` 완료 — 미충족 항목 없거나 해소 계획 있음
- [ ] `output/conformance/declaration-draft.md` 최종 검토 완료
- [ ] 선언 범위(적용 소프트웨어/제품)가 명확히 정의됨
- [ ] 승인 권한자(경영진 또는 담당 임원)의 사전 동의 확보

### 2단계 — 자체 인증 체크리스트 내려받기

https://github.com/OpenChain-Project/Reference-Material/tree/master/OpenChain-Standards-Self-Certification

`Checklist/ISO-IEC-5230` 및 `Checklist/ISO-IEC-18974` 아래에 언어별 파일이 있다.

### 3단계 — 표준 선택 및 자체 점검

| 인증할 표준                          | 선택 |
| ------------------------------------ | ---- |
| ISO/IEC 5230 (라이선스 컴플라이언스) | ☐    |
| ISO/IEC 18974 (보안 보증)            | ☐    |
| 두 표준 모두                         | ☐    |

체크리스트의 각 항목을 Yes/No 로 판정할 때 `output/conformance/declaration-draft.md` 내용을 참고한다.

### 4단계 — 등재 신청

https://openchainproject.org/get-started 의 온라인 신청 폼을 작성해 제출한다.
체크리스트 자체를 업로드하는 방식이 아니라, 자체 점검을 마쳤다는 전제로 회사 정보를 제출한다.

### 5단계 — 인증 완료 확인

등록 완료 후:

- OpenChain 공식 인정 기업 목록에 등재됨
- OpenChain 로고 사용 가능 (사용 조건 확인 필요)

### 리마인더 설정 방법

만료일 1개월 전 알림을 아래 방법으로 설정한다:

- 담당자 캘린더에 "OpenChain 재선언 준비" 일정 등록
- 팀 채널(Slack/Teams 등)에 주기적 리마인더 봇 설정

---

## 3. 재선언 준비 절차 (18개월 후)

재선언 시기가 되면 아래 순서로 준비한다:

1. `agents/07-conformance-preparer`를 재실행하여 갭 분석 업데이트
2. 변경된 정책·프로세스 반영 여부 확인
3. 지난 18개월간의 취약점 대응 이력 및 교육 이력 확인
4. `output/conformance/declaration-draft.md` 업데이트 (날짜, 범위 변경 여부 등)
5. OpenChain 웹사이트에서 재선언 등록
