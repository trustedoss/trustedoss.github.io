## What this site is

trustedoss.dev is a hands-on hub covering open source trust end to end,
from building a company's open source management program
to enforcing that policy automatically inside AI coding tools.

## What it covers

- **Building the program**: ISO/IEC 5230 & 18974 self-certification
- **AI coding**: policy configuration for Claude Code, Cursor, and similar tools
- **DevSecOps**: pipeline security automation (in progress)
- **Reference**: policy samples and tool guides (in progress)
