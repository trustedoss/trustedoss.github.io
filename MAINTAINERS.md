## What maintainers do

- Review and merge pull requests
- Triage issues and manage releases
- Make the final call when readings of ISO/IEC 5230 or 18974 differ

---

## From contributor to maintainer

An existing maintainer nominates a steady contributor, and the nomination carries if no one
objects within a week. Nominations usually follow these markers.

- Five or more meaningful contributions merged
- Activity within the last three months
- Experience reviewing someone else's pull request

If you would like to become a maintainer, start by contributing. Open an issue if you have
questions.
